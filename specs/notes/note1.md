


## Commands for git: merge, branch etc
git switch -c connect-to-mongodb

Commit your changes with a clear message:
git add .
git commit -m "Connected app to MongoDB"
Push the branch to GitHub:
git push origin connect-to-mongodb


Switch back to the main branch:
git switch main
Pull the latest changes:
git pull origin main
Delete the local feature branch:
git branch -d connect-to-mongodb
